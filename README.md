# Muisti

Transform words into meaningful context with minimal black and white design.

## Features

- Add words to build your vocabulary
- Generate contextual text that incorporates your words
- Minimal, stylish black and white UI
- Responsive design

## Tech Stack

- **Framework**: Next.js 16 with App Router
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Components**: shadcn/ui
- **Testing**: Vitest (unit tests), Playwright (e2e tests)
- **Package Manager**: pnpm
- **Deployment**: Vercel

## Getting Started

### Prerequisites

- Node.js 18+
- pnpm

### Installation

```bash
pnpm install
```

### Development

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Testing

Run unit tests:
```bash
pnpm test
```

Run e2e tests:
```bash
pnpm test:e2e
```

### Build

```bash
pnpm build
pnpm start
```

## Deployment

This project is configured for deployment on Vercel. Simply push your code to a Git repository and connect it to Vercel.
